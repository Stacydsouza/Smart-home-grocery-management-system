🛒 GroceryIQ - Smart Home Grocery Manager
A modern, responsive web application designed to help users manage their household inventory, track grocery items, and organize shopping lists in real-time. Built with React and powered by Supabase.

✨ Features
Live Dashboard: View all your grocery items and their current status at a glance.

Real-time Database: Powered by Supabase to ensure your inventory stays synced across devices.

Responsive Design: Optimized for both mobile and desktop use to help you while you're at the store.

Efficient State Management: Uses React Context API (AppContext.jsx) for seamless data flow.

🛠️ Tech Stack
Frontend: React.js with Vite.

Backend/Database: Supabase.

Styling: Modern CSS for a clean, user-friendly interface.
